# Tic-Tac-Toe in C

A simple command-line Tic-Tac-Toe game written in C.

I originally created this project during my first semester while learning C programming. It was one of my early projects for practicing programming logic, arrays, functions, loops, and conditional statements.

## Features

- Two-player gameplay
- 3×3 game board
- Position-based input (1–9)
- Automatic win detection
- Draw detection
- Prevents overwriting occupied positions

## Concepts Used

- C programming
- 2D arrays
- Functions
- Loops
- Conditional statements
- User input
- Basic game logic

## How to Compile

Using GCC:

```bash
gcc tic_tac_toe.c -o tic_tac_toe
